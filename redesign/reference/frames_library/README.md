# Library frames (Phase 5)

Frames of the designer's video at 2 per second, 1280 px wide, for the Phase 5 work (library,
music, playlists, network streams, home, recent, pins, compact library, mini player).

- Name: `t_MM-SS.d.jpg` = video time minutes, seconds, tenths (0 or 5); accurate to about 0.25 s.
- Segments: the time ranges of every row in redesign/BUILD_PLAN.md section 8 with a W5.x work
  package plus every redesign/VIDEO_INDEX.md row with area "library", merged; plus 13:09-13:13
  (Open Network Stream dialog, W5.4a) and 10:03-10:12 (how the library was reached before).
  - 9:35-12:28 (348 frames): library chapter, compact library, drag to queue, mini player, music
  - 13:09-13:55 (94 frames): network streams, playlists, New Playlist, pins, recent
  - 20:08-20:23 (32 frames) and 20:52-20:59 (16 frames): closing montage
- Read them with the transcript (`../vlc_redesign.en.srt`) at the same times: some frames show
  older versions or rejected ideas before the final one. The look comes from the Figma final UIs.
