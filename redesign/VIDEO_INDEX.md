# VIDEO_INDEX: Juxtopposed "I Redesigned VLC After 25 Years"

Index of every change, screen, control, menu, behavior and feature shown or mentioned in the designer's video (20:59, `redesign/reference/vlc_redesign.mp4`), in video order. This is a checklist so nothing gets missed. It does NOT replace the video: before building any item, go back to its timestamps, read the matching transcript lines (`redesign/reference/vlc_redesign.en.srt`), pull dense frames, and check the Figma PNGs (`redesign/reference/figma/`). Colors come only from `figma/styles.txt`.

## How this was made
- 1 fps frames of the whole video (1260 frames, `frames_work/full/`) reviewed as 4-second contact sheets in 8 sections, all sheets, each alongside the transcript and the Figma PNGs. Dense extra frames (2 to 10 fps) were pulled where menus open, panels slide or bars hide.
- Two extra passes over the whole video for video-only visuals: icons and their states, shapes, typography, slider/toggle styles, transitions. The video has more detail than Figma, so rows with no PNG say "none (video only)" and still count fully.
- IDs: `P1` to `P8` = section passes (P1 0:00-3:03, P2 3:04-5:39, P3 5:40-7:51, P4 7:52-9:23, P5 9:24-11:59, P6 12:00-14:11, P7 14:12-17:35, P8 17:36-20:59). `IA` / `IB` = visual passes (first and second half). Rows are sorted by start time, so several rows can cover the same moment from different angles (function vs look). Read all rows near a timestamp.
- `F-01` to `F-23` = interactions and details from the Figma prototype that the video does not show (section "Items from the Figma prototype" after the main index). Exact sizes, spacing, radius, fonts and every prototype interaction are in `redesign/FIGMA_FLOWS.md`.

## Columns
- **Area**: control bar, top bar, sidebar, library, menus, settings, subtitles, audio/video, playlists/queue, visual style, other.
- **Type**: `UI` = restyle or relayout of something VLC 4 already does. `NEW` = needs functionality VLC does not have today. A `?` means the reviewer was not sure.
- **Status**: todo / in progress / done / blocked. Update it as work happens.
- Rows about old VLC problems, B-roll, the sponsor, memes and survey charts are kept for context (they explain WHY a change exists) but have nothing to build. There are 59 of them; they are marked by words like "Old", "problem", "context", "B-roll", "sponsor", "meme", "survey" in the Item column.

## Decisions (Tony)
Decided by Tony on 2026-10-12. General rule for anything not listed: her final version in the video wins; the Figma prototype fills in what the video does not show.

1. Fullscreen button in the top bar. Picture-in-Picture skipped for now.
2. Main "..." menu: her last version, matching Figma menu.png.
3. Queue: tabbed sidebar with Queue / Bookmarks / Chapters, everywhere.
4. Bars show on hover near them and hide instantly when the mouse moves away.
5. Gear opens the settings sidebar on the Playback tab. Subtitle and audio buttons open the tracks popup on their tab.
6. Seek thumbnail shows anywhere along the seek bar while hovering.
7. Volume range 0 to 200%.
8. Home page includes "Latest Streams".
9. Onboarding: picking a theme or accent color recolors the app live.
10. Mini player queue header: the video's 5 icons.
11. Wording: the video's wording where it differs from Figma.
12. External Tracks "+": Figma's "To This File / From Computer" flow with the language list.
13. Playback tab: the video's items (including Show Waveform on Seekbar and Show Metadata) plus Figma's Show Statistics.
14. Prototype placeholder links (About VLC, Quit VLC, More Settings, Open Media, right-click Playlist): wire each to its real action.
15. Accent color options: #D37918, #E15032, #C49E23, #19A234, #18AAD3, #185DD3, #8E42FF, #F052B3, #AFAFAF. Added to styles.txt.
16. Menu icons use Accent/DIm #AB6314.
17. Fix the design typos.
18. Presets: one preset per show covering all tabs (subtitles, audio, video, playback).
19. Gear icon: the Figma version.
20. Dark theme first. Light theme last: propose corrected Light/FG/1 and FG/2 values (proposal to confirm then: Light/FG/1 #141414, Light/FG/2 #262626).
21. Features with no Figma frame: build from the video, styled to match the Figma components.
22. Keep all VLC default shortcuts. F = fullscreen, V = cycle subtitle track. Hide UI = Ctrl+\. Add Ctrl+B = create bookmark. Ignore the prototype's F and V bindings.
23. Sleep Timer: Off / 15 / 30 / 45 / 60 min / End of current file.
24. Show Metadata opens a file info panel. "Render: Local" is VLC's existing renderer/cast picker.
25. Per-preset "..." menu: Rename, Duplicate, Delete. Profile "+ New": enter a name, copy current settings.
26. Info icon: click shows the setting's description in a popover.
27. Core changes approved wherever a feature truly needs them, minimal and isolated. Examples: OSD showing the pressed shortcut, subtitle timeline (external files first, embedded later if feasible).
28. Accepted limit: subtitle outline uses VLC's existing outline sizes.
29. Postponed: reverse playback. Profiles may need a restart for some settings; show a notice when that happens.
30. (2026-10-13, updated) Windowed: both bars float over the video, appear whenever the mouse moves over the window and fade out about 3 s after it stops (with the cursor), like modern players. Fullscreen: each bar appears when the mouse is near its edge and fades out smoothly when it leaves. VLC's own "pin video controls" option still pins both bars in a window.
31. (2026-10-13) The final UIs are in the Figma file; the video shows iterations on the way. Look: Figma. Functionality and relations: the video and its transcript.

## Decisions (Claude)
Extra decisions made during the build, one line each (date, row IDs, decision, reason).
- 2026-10-13 P1-05 / W2.1: dark palette mapping to VLC color sets: View bg BG/A3, secondary BG/B2, main text FG/A1, secondary text FG/A3, borders Divider/Bright, separators Divider/Dim, icon buttons FG/A2 with #FFFFFF 6% hover, accent buttons solid accent + FG/B1 text, standard buttons BG/A3 + FG/A2 (Figma Cancel). Reason: Figma uses FG/A1-FG/A3 grays for almost all text, brighter FG/2-FG/1 only for hover/selected.
- 2026-10-13 W2.1: dark ("Night") is the default color scheme when the user has none saved (Decision 20).
- 2026-10-13 W2.1 / Decision 20: proposed Light/FG/1 #111111 and Light/FG/2 #222222 (the Figma file repeats the dark values); all other light tokens are the Figma Light styles. Needs Tony's OK before the light theme ships.
- 2026-10-13 W2.1: a custom accent derives its Bright / DIm / BG shades with the same saturation and value ratios as the active theme's own Figma accent set; the default accent maps to each theme's exact Figma set (dark #D37918, light #E8851A).
- 2026-10-13 W2.1: Inter ships as the five static weights the Figma file uses (300, 400, 500, 600, 700) instead of the variable font, because static files group reliably under the "Inter" family on Qt's DirectWrite backend. Inter becomes the application font. DM Mono (9 text layers in Figma) is not bundled until its use is identified.
- 2026-10-13 W2.3: window buttons use the Figma minimize / maximize / close icons; the Figma set has no restore icon, so maximize is shown in both window states. The speaker icon uses Figma volume_value-high; the design has no muted icon, so muted keeps VLC's muted glyph.
- 2026-10-13 W2.3: checked control bar buttons and active tabs switch to the filled "state-active" Figma variant (video 4:40 audio button and tab).
- 2026-10-13 Decision 22: the right-click Record item shows VLC's Shift+R (the Figma "R" is VLC's Random key); the onboarding shortcuts screen (19:50) lists VLC's default keys, not the prototype's. Ctrl+B becomes Create Bookmark, so Manage Bookmarks loses its old shortcut (found by RESIDUAL_AUDIT).
- 2026-10-13 W4.3a-W4.6 (Step 1): the settings sidebar shows only rows VLC already supports. Show Subtitle Timeline / Waveform / Metadata / Statistics, Reverse, Sleep Timer (W4.3b), the per-show preset selector (W4.7) and the Stereo Mode "Test" button (no VLC function) come with Step 2, in the video's places.
- 2026-10-13 W4.6: VLC 4 only scales subtitles relative to the video (sub-text-scale, live); the "Relative / Pixels" choice (7:40, "precise values") needs a small core option for a pixel size: proposed for Step 2 under Decision 27. Font Size shows the relative scale (100 % = "Auto"). Font, colors, outline and background are VLC options read when subtitles are rendered for a new file, so the section says "apply from the next file" (Decision 29); live updates would need a core change too.
- 2026-10-13 W4.3-W4.6: slider thumbs and "Open Advanced Settings" follow the Figma final UI (Accent/DIm thumb; BG/B2 bar button with a gear), per Tony's rule that Figma holds the final UIs. "Open Advanced Settings" opens VLC's preferences until the redesigned settings dialog (W6.1) can open on the matching category (F-08).
- 2026-10-13 W4.4: Geometry, Overlay and Advanced filter cards have no Figma content; they list VLC's effects of the same tabs (magnify, wall, puzzle / logo, marquee, logo erase / anaglyph, mirror, psychedelic, waves, water, motion detect, spatial blur, motion blur, anti-flickering, denoiser, clone) with the Essential / Colors card style (Decision 21). Flip and Rotate live in Defaults, so the Geometry card leaves out transform and rotate. Every filter value is live and saved.
- 2026-10-13 W4.8: queue rows: click selects (for the remove button), double click plays, the handle drags the row; sort sorts by title and toggles the order. Bookmarks "+" and "-" open VLC's bookmark editor until Ctrl+B and instant bookmarks (W4.8b). Bookmarks show only when the media library is available (VLC keeps bookmarks there).
- 2026-10-13 W2.3 / W2.2: every orange part of every icon must follow the live accent color (accent setting, video 17:44): SVG icons use the colorizer placeholders (`_res_ACCENT` for accent parts, `_res_C2` for Accent/DIm two-tone parts, `_res_C1` for gray) bound to `palette.rd*`, never baked-in orange. (Tony reminder 2026-10-13.)
- 2026-10-13 W4.2: the tracks popup lists all tracks under "Embedded Tracks" for now (VLC's track model does not mark external files); External Tracks "+" uses VLC's load-subtitle action until the Add Subtitles dialog (W6.5); "Show Preferences" opens VLC's effects dialog until the settings sidebar tabs (W4.3-W4.6) exist. The output-device refresh icon re-reads the device list (VLC only read it at startup; new AudioDeviceModel.refresh()).
- 2026-10-13 W2.1: Figma colors are exposed to QML as `palette.rd*` (systempalette.hpp) and Figma sizes as `VLCStyle.rd_*` tokens, so components use exact design values.
- 2026-10-13 Decision 30: in a window the bars and cursor hide 3 s after the mouse stops (VLCStyle.rd_barsHideDelay); fullscreen keeps VLC's "mouse-hide-timeout" preference (Tony: the 3 s is for windowed only); a window keeps reacting to mouse moves while another app is active (cursor polled, VLC's video surface does not report hover).
