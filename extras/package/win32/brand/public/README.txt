Cone
====

Cone is a free and open source media player for Windows, based on VLC media player.
It is an experimental build: it tracks VLC 4 development code.

Start
-----
Run Cone.exe in this folder. Nothing needs to be installed.

Cone keeps its settings in %APPDATA%\Cone, apart from an installed VLC media player.
To keep them inside this folder instead, create a folder named "portable" next to Cone.exe.
